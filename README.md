# 🏥 MediQueue — Clinic Token Management System

**MediQueue** is a modern, real-time clinic token and queue management system designed to simplify patient registration, token generation, doctor-wise queue management, and live patient tracking.

### ✨ Features

- 🎫 **Smart Token Management** — Generate and manage patient tokens efficiently.
- 👨‍⚕️ **Doctor-wise Queues** — Separate queues for different doctors and rooms.
- 📋 **Admin Dashboard** — Manage patients, doctors, tokens, and clinic settings.
- 🔄 **Real-Time Queue** — Live updates using Firebase Firestore.
- 📺 **Public Queue Display** — Show Now Serving and Waiting patients in real time.
- 👤 **Patient Portal** — Patients can generate and track their tokens without accessing the admin panel.
- ⚡ **Call Next System** — Safe `WAITING → CALLED → IN CONSULTATION → COMPLETED` workflow.
- 🔐 **Role-Based Access** — Separate access for administrators, doctors, staff, and patients.
- 🏥 **Multi-Clinic Ready** — Designed to support isolated clinic-wise data and queues.
- 📱 **Responsive UI** — Clean and professional interface for desktop and mobile.

### 🔄 Queue Workflow

`WAITING → CALL NEXT → CALLED → IN CONSULTATION → COMPLETED`

Additional actions:

`SKIP` • `CANCEL`

### 🛠️ Tech Stack

**React • TypeScript • Vite • Tailwind CSS • Firebase Authentication • Cloud Firestore • Google GenAI**

### 🎯 Goal

MediQueue replaces traditional paper-based clinic token systems with a centralized digital solution that improves patient flow, reduces manual queue management, and provides real-time visibility for doctors, staff, and patients.
